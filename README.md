# MLG ROVER Ω · montagem no Meta Quest 3S

Abra no navegador do Quest: **https://math741.github.io/mlg-rover-quest/**

- **Montar com o Quest**: o rover em holograma no tamanho real na mesa, passo a passo; a câmera do Quest reconhece as peças pelos adesivos ([folha de adesivos](adesivos.pdf), imprima em 100%).
- **Montagem na tela**: o mesmo passo a passo no celular ou PC.
- Pilotar só funciona pelo endereço do próprio rover (Raspberry Pi): `https://rover.local:8443`.

Feito com three.js (MIT) e js-aruco2 (BSD); licenças em `vendor/`.
